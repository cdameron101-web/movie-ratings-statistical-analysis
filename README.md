# movie-ratings-statistical-analysis
A Python statistical analysis project using Pandas, NumPy, and Matplotlib to clean and visualize simulated movie ratings, perform exploratory data analysis (EDA), and estimate average ratings using 95% confidence intervals.


# 🎬 Movie Ratings Statistical Analysis

## Project Overview

This project was completed as part of the **Statistics Bootcamp (with Python): Zero to Mastery**.

The objective was to practice data preparation, exploratory data analysis (EDA), statistical estimation, data visualization, and automated reporting using Python.

The project uses simulated movie ratings to demonstrate an introductory statistical analysis workflow.

## Technologies Used

- **Python** — Data processing and statistical analysis
- **Pandas** — Data cleaning and manipulation
- **NumPy** — Numerical calculations and simulated data generation
- **Matplotlib** — Data visualization
- **Google Colab** — Development environment

## Project Workflow

### 1. Data Preparation and Cleaning
- Created a movie ratings dataset.
- Identified missing values and duplicate records.
- Practiced cleaning data using Pandas.

### 2. Exploratory Data Analysis (EDA)
- Calculated mean, minimum, and maximum ratings.
- Examined rating frequencies and descriptive statistics.
- Created a bar chart using Matplotlib.

### 3. Statistical Estimation
- Generated 100 simulated movie ratings.
- Calculated sample mean and standard deviation.
- Calculated standard error.
- Constructed an approximate 95% confidence interval for the population mean.

### 4. Statistical Conclusions
- Interpreted statistical results.
- Explained confidence intervals.
- Generated a formatted statistical report using Python.
